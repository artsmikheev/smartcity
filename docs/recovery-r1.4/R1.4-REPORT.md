## 1. Что реализовано

**Каталог — без смены композиции и tab bar.** Архитектурные JPG в карточках заменены на SVG-схемы. Для пяти layouts подготовлены `studio-25.svg`, `one-room-38.svg`, `two-room-55.svg`, `two-room-62.svg`, `three-room-78.svg`. Фон `#121212`, grid 8px с opacity .06, gold-стены 2px и дверные проёмы, прямоугольники кроватей и круглые столы, muted подписи 8px. Во всех схемах указано «СХЕМА», «ДЕМО · НЕ В МАСШТАБЕ». Это редактируемые schematic placeholders, не реальные обмерные/утверждённые планировки. Генератор `scripts/generate-plans.mjs` создаёт оригинальные SVG и идентичный XML manifest из одной модели. `ApartmentMedia` использует `SvgXml` из react-native-svg для SVG, а не native raster Image decoder; остальные изображения идут через expo-image. Resolver содержит literal local requires всех пяти SVG.

Тень horizontal/compact карточек: `0 10 24 rgba(0,0,0,.55)`, elevation8 на native; отдельный outer shadow wrapper без clipping и inner clip. Edge `#2E2C2A`, 1px, inset overlay не меняет принятые padding16/height160. Heart: подложка rgba(28,27,26,.85), граница rgba(255,255,255,.15), 1px shadow underlay того же Ionicons glyph; визуальный круг44, hit48. Режим «Чертежи» показывает schematic assets, не ошибочно пустое состояние. Маркировка только в footer: «Схематичные планировки, демо-данные».

**Detail `/apartment/[id]`.** Hero55% viewport, SVG, нижний затемняющий градиент; back/heart/menu hit48, круг44. Метаданные11, Playfair title32, цена34 bold, gold статус13. CTA52 в контенте и sticky bottom с градиентом только фона, учитывает safe area. Facts2×2, секция полной схемы и горизонтальный список из трёх compact280×140 карточек. Отделка «По запросу», поскольку SQL не содержит подтверждённых сведений. Not-found/loading/error не маскируются demo контентом.

**Home.** Playfair36, project hero260 с градиентом, title28/body15, disclaimer вне изображения; три quick actions. Store-backed компактное избранное скрыто при отсутствии сохранений. «Ход строительства» и две demo promo-карточки ведут только на существующие routes/форму. Notification и All promos открывают локальные informative Modals, не имитируют push/сетевой feed и не создают Package2. Заголовки акций и октябрьский отчёт взяты из seed; неподтверждённое «3 дня назад» не выдано за факт.

**Favorites.** Принятые horizontal cards, счётчик, удаление, точное empty состояние. Общий module-stable store на useSyncExternalStore; AsyncStorage только lazy client effect. Hydration не теряет быстрые toggles, writes сериализованы. Локальная storage-ошибка явно видна, данные остаются доступными в памяти. Серверная синхронизация не заявляется. Favorites доступен из Home/Detail menu, а не пятой кнопкой навигации: пользователь ранее сохранил «Стройка» вместо «Избранное».

**Lead + Success.** RHF/Zod, inputs52/radius12/font16, inline errors и aria-invalid, RU mask с paste8→+7, channels56 и keyboard arrows/Space, checkbox22/hit48 и отдельная underlined consent ссылка. Опубликованная актуальная версия согласия читается из Supabase; demo legal copy явно не утверждена и не допускает реальную отправку. Duplicate tap lock берётся до async validation. При настоящей отправке navigator removal guard блокирует аппаратный back/edge; успешный переход выполняется после снятия guard. API динамически загружает клиент после env guard, передаёт типизированные RPC Args, принимает только проверенный серверный public_reference. Demo-флаг и readonly проверки is_demo объекта независимы от UUID-валидности. Номер в URL не доказывает успешную отправку. Завершение flow через dismissTo возвращает на существующий экран. Demo success имеет «ЗАЯВКА НЕ ОТПРАВЛЕНА» и `DEMO-REFERENCE`, не фальшивую квитанцию.
