## Токены и миграция импортов

`constants/app-data.ts` содержит только COLORS, TYPOGRAPHY, SPACING, RADIUS со значениями из спецификации. `constants/theme.ts` содержит только:

```ts
export { COLORS, TYPOGRAPHY, SPACING, RADIUS } from './app-data';
```

Все runtime-потребители переведены на этот entry point. Не-токенные данные из старого app-data перенесены **дословно** в constants/mock-data.ts. Для совместимости NativeWind/стартерных компонентов обновлены theme.config.js, ThemeProvider, useColors и theme-lab: семантические имена ссылаются на новые COLORS, а не на отдельные значения. В коде нет прежнего #484848, старой runtime Colors/Fonts-палитры и старых цветовых ключей lime/sand/amber/surface.

Тема по умолчанию тёмная. Дополнительной светлой палитры нет — обе позиции существующего debug-переключателя используют одну бренд-палитру. Sans fontFamily оставлен undefined, не «System».

Изменения экранов: только импорты, переименование удалённых токенов и paddingBottom 130 в ScrollView четырёх табов. Старые композиция, типографика экранов и demo-логика остаются для R1.3+. Загрузка Playfair не означает, что экран уже перевёрстан этим шрифтом.

## Контраст

Скрипт scripts/contrast.mjs рассчитывает относительную яркость по WCAG: sRGB channel ≤0.04045 → channel/12.92, иначе ((channel+0.055)/1.055)^2.4; L=0.2126R+0.7152G+0.0722B; ratio=(Lmax+0.05)/(Lmin+0.05).

| Новая пара | Ratio | AA |
|---|---:|---|
| foreground / background | 14.32:1 | PASS |
| muted / cardBackground | 7.93:1 | PASS |
| accent / cardBackground | 5.13:1 | PASS |
| accentForeground / accent | 5.77:1 | PASS |
| foreground / pill over white | 12.58:1 | PASS |
| muted / pill over white | 7.74:1 | PASS |

В полной contrast.md — 21 проверенная пара, все проходят AA в заданной роли. Для полупрозрачной pill проверен максимально светлый подслой (white), sRGB alpha composite #272625. Это проверка новых фундаментальных пар, не WCAG-сертификация старых экранов. mutedDark не используется в новом tab bar для смысловых подписей.
