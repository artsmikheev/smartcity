## 2. Блок B — Edge Function

Созданы:

- `supabase/functions/notify-lead/index.ts`;
- `supabase/functions/notify-lead/index.test.ts`;
- `supabase/functions/notify-lead/deno.json`;
- `supabase/functions/_shared/cors.ts`;
- `supabase/functions/_shared/types.ts`;
- `.env.example`;
- `docs/BACKEND-R2.md`.

Handler принимает только POST. Проверяются webhook secret, `type=INSERT`, `table=leads`, `schema=public` и минимальные поля record. Message отправляется в Telegram Bot API с `parse_mode=HTML`, `disable_web_page_preview=true`. Значения HTML-экранируются. Москва форматируется как `DD.MM.YYYY HH:mm` через `Europe/Moscow`.

При Telegram `ok=true` возвращается `200 {"ok":true}`. При ошибке Telegram или отсутствии server-side Telegram configuration возвращается `500 {"error":"telegram_failed"}`.

Логи содержат только `public_reference`, `request_type` и безопасный код ошибки. `name`, `phone`, `comment` никогда не передаются в `console.log/error`.
