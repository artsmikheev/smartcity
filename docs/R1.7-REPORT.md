| Detail translucent controls | raw rgba literals | semantic overlay roles | 3 | использовать `scrim/overlay/overlayStrong` |

| Catalog density | функциональная карточка начиналась близко к chrome | воздух между title/filter/list | 3 | не менять принятую карточку без отдельного UI approval |
